# 智枢AI SaaS 完整菜单改造方案

**日期**: 2026-08-05
**最后修订**: 2026-08-06（功能开关合并进客户管理）
**状态**: 已完成并持续优化

---

## 一、WEB 端

### Admin 总后台（不变，共10项）

| # | 菜单名称 | 功能说明 |
|---|---------|---------|
| 1 | 数据总览 | 全平台核心指标仪表盘（客户数、代理商数、API 消耗量、活跃度） |
| 2 | 客户管理 | 所有终端客户列表、详情、账户状态管理。**内置功能开关管理**：在客户详情中为每个客户单独配置功能模块启用/停用，数据来源 FeatureSwitch DB 动态加载，与 Agent 端共享功能开关库 |
| 3 | 代理商管理 | 代理商列表、审核、分组、上下线管理 |
| 4 | API 服务商 | 管理第三方 AI 供应商（阿里云百炼、火山引擎、DeepSeek 等）的统一配置 |
| 5 | 系统公告 | 发布和管理全平台公告（推送到 Agent / Customer 首页） |
| 6 | 操作日志 | 全平台审计日志查询（谁在什么时候做了什么） |
| 7 | 版本管理 | 平台版本号管理与更新发布记录 |
| 8 | 客服配置 | 上传/更换企业微信二维码。Agent 的"客服中心"和 Customer 的"在线客服"展示的就是这张二维码 |
| 9 | API 统计 | 全平台 API 调用量统计与图表 |
| 10 | 系统设置 | 修改密码、退出登录 |

---

### Agent 代理后台（改造后 7 项）

| # | 菜单名称 | 功能说明 |
|---|---------|---------|
| 1 | 数据总览 | 名下客户的汇总数据（客户数、活跃客户数、API 总消耗量、新增客户趋势图） |
| 2 | 客户管理 | 名下客户列表及详情。**功能开关已合并进客户管理**：在客户详情中为每个客户单独配置功能模块启用/停用（AI创作工厂、智能招聘、智能获客、推荐分享等），按客户粒度控制，数据来源 FeatureSwitch DB 动态加载 |
| 3 | 用量统计 | 名下客户的 API 用量明细和消耗金额统计（按客户、按功能维度） |
| 4 | 工单处理 | 名下客户提交的工单列表与处理 |
| 5 | 客服中心 | 展示 Admin 上传的企业微信二维码，扫码即可联系平台客服 |
| 6 | 分成结算 | 佣金分成明细与结算记录（初期标注"即将上线"） |
| 7 | 系统设置 | 修改密码、退出登录 |

**删除项**: AI创作工厂、内容中心、API管理、"功能开关"独立一级菜单（已合并进客户管理）

---

### Customer 终端客户（改造后 9 项）

| # | 菜单名称 | 功能说明 |
|---|---------|---------|
| 1 | 数据总览 | 个人数据概览（内容产出统计、招聘进度、获客转化漏斗、API 消耗量） |
| 2 | AI创作工厂 | 文本/图文/短视频/数字人/萌宠卡通/图片生成/视频生成/AI文案/AI剪辑/声音克隆 等全系列内容创作工具 |
| 3 | 智能招聘 | 职位发布 → AI 自动搜索 → 自动打招呼 → 简历筛选 → 邀请面试 → 招聘统计看板 |
| 4 | 智能获客 | 潜客发现（抖音/快手/小红书/B站/天眼查/高德地图全平台采集）→ 引流任务 → 获客看板 → 转化统计 |
| 5 | 推荐分享 | 短视频二维码生成 → 分享追踪 → 转介绍统计 → 裂变漏斗 |
| 6 | 内容中心 | 已创作内容的资产管理（素材库、作品列表） |
| 7 | 工单管理 | 提交新工单、查看工单处理进度与历史 |
| 8 | 在线客服 | 展示 Admin 上传的企业微信二维码，扫码联系客服 |
| 9 | 设置 | 安全设置、API管理（第三方 AI Key 配置）、APP下载 等全部非业务配置收纳于此 |

**删除项**: 独立的"登录日志"一级菜单、"API管理"一级菜单
**新增项**: 智能招聘、智能获客、推荐分享
