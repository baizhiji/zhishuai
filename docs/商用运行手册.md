# 智枢AI 商用运行手册（运维补充）

> 目的：补齐正式商用所需的运维保障，包含数据备份、服务监控、密钥异地备份、客服值守要求。
> 更新日期：2026-08-26

## 一、数据自动备份（已落地）

生产服务器（150.109.60.130）每日自动备份，由 crontab 驱动：

- **脚本**：`/var/www/zhishuai/scripts/db-backup.sh`（仓库内 `scripts/db-backup.sh`）
- **定时**：每日 02:00（crontab：`0 2 * * *`）
- **备份内容**：
  - MySQL 数据库（`mysqldump --single-transaction --routines --triggers --set-gtid-purged=OFF`，TDSQL-C 内网 172.19.0.13:3306/zhishuai）
  - 用户上传文件 `uploads/` 目录
  - 服务配置 `server/.env`
- **存放目录**：`/var/www/zhishuai/backups/`（命名 `zhishuai_YYYYMMDD_HHMMSS.sql.gz`）
- **保留策略**：30 天滚动清理（脚本自动删除过期文件）
- **日志**：`/var/log/db-backup.log`
- **手动触发**：`bash /var/www/zhishuai/scripts/db-backup.sh`

### 恢复演练（每月建议执行一次）

```bash
# 1. 解压备份
zcat /var/www/zhishuai/backups/zhishuai_YYYYMMDD_HHMMSS.sql.gz > /tmp/restore.sql
# 2. 恢复到测试库（切勿直接覆盖生产库）
mysql -h172.19.0.13 -uroot -p<密码> -e "CREATE DATABASE zhishuai_restore;"
mysql -h172.19.0.13 -uroot -p<密码> zhishuai_restore < /tmp/restore.sql
# 3. 抽查关键表行数是否与生产一致
mysql -h172.19.0.13 -uroot -p<密码> -e "SELECT COUNT(*) FROM zhishuai_restore.User;"
```

## 二、服务监控（已落地）

- **脚本**：`/var/www/zhishuai/scripts/monitor.sh`（仓库内 `scripts/monitor.sh`）
- **定时**：每 5 分钟（crontab：`*/5 * * * *`）
- **监控项**：
  - `zhishuai-api` pm2 进程状态，异常自动 `pm2 restart`
  - HTTP 健康检查：`api.baizhiji.net/api/version/latest`、`baizhiji.net`、`baizhiji.net/downloads/zhishuai.apk`
- **日志**：`/var/log/zhishuai-monitor.log`（超 1MB 自动截断）

### 告警接入（建议后续配置）

当前告警仅写日志。建议接入企业微信群机器人或钉钉 Webhook，在 `monitor.sh` 的 `log()` 中追加 curl 通知即可实现即时告警。

## 三、签名密钥异地备份（已落地）

Tauri 更新签名密钥（minisign）备份情况：

| 位置 | 文件 | 说明 |
|------|------|------|
| 本机 `C:\Users\Administrator\Documents\zhishuai-secrets-backup\` | `zhishuai.key` / `zhishuai.key.pub` / `SHA256SUMS.txt` | 主备份 |
| 同目录 | `zhishuai-secrets.zip.enc` | AES-256-CBC 加密包（976 字节） |
| 同目录 | `BACKUP_PASSWORD.txt` | 加密密码（务必妥善保管，建议存入密码管理器） |
| 香港服务器 `/home/ubuntu/zhishuai-secrets-backup/zhishuai-secrets.zip.enc` | 加密包（权限 600） | 异地备份 |

**校验值**：加密包 SHA256 = `59756eee59634cd29d19759ba470190f340e5bc4e805f64ca85cd543798b9f1a`

### 解密恢复步骤

```bash
# 环境：本机（Git 自带 openssl）或任意 openssl 环境
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in zhishuai-secrets.zip.enc -out secrets.zip -pass pass:<BACKUP_PASSWORD.txt 中的密码>
# 解压后得到 zhishuai.key 与 zhishuai.key.pub，放置到 ~/.tauri/zhishuai
```

> 安全提示：私钥丢失后将无法发布新的桌面版更新包。本异地备份 + 密码分置（密码仅本机）+ 建议再在加密云盘存一份密文。

## 四、客服与支持渠道（已确认就绪）

- 客服二维码已配置并生效：`GET https://api.baizhiji.net/api/support/qrcode` 返回 `/uploads/support_qrcode_1787643343266.jpg`（企业微信客服二维码）

- **值守要求（运营事项，需人工保障）**：

  - 建议每周检查一次客服二维码是否过期（企业微信二维码会过期需重新上传）
