## 三、严重问题（阻断商用）

### 问题 1：创建客户接口 500 —— 管理员与代理商均无法发展下级客户

**现象**：管理员和代理商创建客户均返回 500，错误为：

```
Invalid prisma.userFeatureSwitch.createMany() invocation:
Argument `updatedAt` is missing.
```

**根源**：`server/prisma/schema.prisma` 中 `UserFeatureSwitch` 模型的 `updatedAt` 字段定义为 `DateTime`（必填、无默认值），但创建客户时初始化功能开关的代码未传 `updatedAt`。受影响位置（均缺 updatedAt）：

- `server/src/routes/admin-agents.ts:599`（管理员创建客户）
- `server/src/routes/agent.ts:349`（代理商创建客户）
- `server/src/services/admin-agents.service.ts:308`（未被路由引用）
- `server/src/services/agent.service.ts:218`（未被路由引用）
- `server/src/services/auth.service.ts:242`（未被路由引用）

注意：`features` 接口读取时自动初始化的两条路径（agent.ts:528、admin-agents.ts:729）已正确传 `updatedAt`，所以**读取正常、创建异常**。

**影响**：代理商无法开新客户、管理员无法开新客户 → 多租户 SaaS 的"发展下级"核心闭环断裂，**当前不可商用**。

### 问题 2：APK 默认 API 域名未解析

**现象**：`apk/src/services/api.config.ts` 默认 `BASE_URL = 'https://api.zhishuai.cc/api'`，但 `api.zhishuai.cc` **无 DNS 解析记录**（Non-existent domain，服务器与本地双重确认）。

**现状**：生产服务器 nginx 实际配置的 API 域名为 `api.baizhiji.net`（→ 3001）。`www.zhishuai.cc` 解析到 81.70.242.14（另一台服务器，非本机）。

**影响**：APK 若未通过 `EXPO_PUBLIC_API_URL` 环境变量覆盖，将无法连接后端。另 `apk/src/services/webLink.service.ts` 硬编码 `http://43.129.16.148:3001`（旧地址，非当前服务器）。

## 四、其他发现（仅报告现状，未做任何修改）

1. **数字人功能**：后端 `/api/digital-human` 路由仍有 14 个端点，Web 端 `/customer/digital-human` 页面存在（200）。AI 助手的 `digital_human` 任务类型已按蓝皮书 V1.5 删除，但路由与页面未清理——**未删除、未添加，保持原样**。
2. **注册链路**：`/auth/register` 创建用户时手动传了 `updatedAt`，功能开关采用懒初始化（读取时自动补），注册本身可用（需短信验证码）。
3. **死代码**：`auth.service.ts`、`agent.service.ts`、`admin-agents.service.ts` 未被任何路由引用（含同样的 updatedAt 缺陷，但当前不影响线上）。
