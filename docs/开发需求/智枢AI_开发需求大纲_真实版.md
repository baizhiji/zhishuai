## 1. 项目概述与定位

### 1.1 产品定位

智枢AI 是一个 **AI SaaS 多租户超级应用**，为中小企业与个体经营者提供"**内容创作 + 获客 + 招聘 + 裂变**"的一站式 AI 经营工具集。核心价值主张：

- **AI创作工厂**：一句话生成图文 / 图片 / 视频 / 数字人内容，自动沉淀素材库
- **智能获客**：自动采集潜客线索，辅助精准营销
- **智能招聘**：AI 自动猎头，岗位发布 → 简历筛选 → 邀约全流程
- **推荐分享**：分享裂变 + 转介绍返佣，驱动增长
- **APK 端 AI 助手**：企业策划 / 经营诊断对话式生成，一键导出 Word/Excel/PPT/PDF

### 1.2 目标用户

| 角色 | 说明 | 典型账号 |
|---|---|---|
| **Admin 管理员** | 平台开发者 / 总后台 | 18601655222 |
| **Agent 代理商** | 区域代理，管理名下客户与收益 | 13900000099 |
| **Customer 客户** | 终端付费用户，使用全部业务功能 | 13800000001 |

### 1.3 系统架构

| 层级 | 技术 | 目录 | 部署 |
|---|---|---|---|
| Web 前端 | Next.js 14 + React 18 + TypeScript + Ant Design 6 + Tailwind CSS | `web/` | 腾讯云 CVM 香港 150.109.60.130 |
| 后端 API | Express 4 + TypeScript + Prisma ORM + MySQL | `server/` | TDSQL-C MySQL 172.19.0.13:3306 |
| 移动端 | Expo SDK 52 + React Native 0.76 | `apk/` | 应用商店 / 侧载 |
| 共享类型 | TypeScript | `shared/` | — |

### 1.4 业务模式

SaaS 订阅制 + 代理分销：
- 客户付费开通功能 → 消耗 AI Token
- 代理商发展客户 → 获取佣金（推荐分享 / 转介绍）
- Admin 平台运营 → API 服务商配置下放、品牌定制、公告、数据总览

## 7. M6 AI 模型配置与管理（总蓝皮书执行摘要）

> 完整规格见《智枢AISaaS系统AI模型配置总蓝皮书 V1.5》。本章为开发需求视角的执行摘要，**新功能开发必须遵守本章的模型路由与横切关卡规范**。

### 7.1 服务商与模型体系（三服务商）

当前 `web/lib/ai/category-config.ts` 已注册的模型清单（**配置层已实现**）：

| 服务商 | 能力域 | 已注册模型 |
|---|---|---|
| 腾讯云 TokenHub | 文本 | DeepSeek V4 Pro、混元 Vision 2.0（多模态） |
| 阿里云百炼 | 文本/图像/视频/TTS | Qwen 3.7 Max、Qwen Max、Qwen 3.7 Plus、Qwen 3.8 Max、千问图像 3.0 Pro、千问图像 Max、千问图像编辑、千问 TTS Plus |
| 火山方舟（配置中） | 视频 | 可灵 KLING 3.0、混元视频 1.5、优图视频 2.0、Vidu Q3 Pro/Turbo、HappyHorse 1.1 T2V / 1.0 VideoEdit、数字人（数人） |
| 第三方接入 | 图像/语音 | 混元 Image 3.0/Lite、WAN 2.7 图像 Pro、Z-Image Turbo、Kimi K3、MiniMax Speech 2.8 HD |

### 7.2 五大横切能力（所有产线必经）

1. **违禁内容检测（Content Safety Gate）**：文本/图片生成前后安全审查，拒绝违规输出
2. **去 AI 化检测（Anti-AI Detector）**：反AI化重写，降低机器味（小红书口语化等）
3. **爆款内容创意（Viral Gene Injector）**：生成前爆款意图分析，注入流量基因
4. **质量优先（Quality Gate）**：多模型交叉评审，择优输出
5. **AIGC 标识合规（AIGC Labeling Gate）**：生成内容自动加 AIGC 标识，符合监管要求

### 7.3 模型路由规则（开发必须遵守）

- 每类任务有 **primaryModel + fallbackModel**（主模型失败自动切换备选）
- 关键参数（temperature / top_p / frequency_penalty）在 `category-config.ts` 中按阶段配置
- **成本控制**：文本高性价比默认 DeepSeek/Qwen Plus 级，创意发散才用旗舰；图片按 n 张批量生成控制成本
- **API Key 管理**：Admin 在 `/api/admin/api-providers` 配置各服务商密钥，密钥加密存储，不落前端

### 7.4 商用级待完善项

- [ ] 模型健康度监控 / 自动降级告警
- [ ] 按客户等级的模型权限分级（免费版/专业版/企业版用不同档位模型）
- [ ] Token 消耗月度报表（`/api/token-stats` 已具备基础，需可视化）
- [ ] 模型动态路由策略（按负载/价格/质量实时选择）

## 10. 商用级整体要求

### 10.1 功能完整度（验收标准）

- [ ] Customer 端能**独立完成**四大业务线全部核心流程（创作→素材→获客→招聘→分享）

- 参数化查询（100% 禁止 SQL 拼接）
- 所有输入 Zod Schema 校验
- 密钥经环境变量 + 服务商配置管理，禁止硬编码
- 全局限流 + 敏感端点限流
- CORS 白名单、Helmet 安全头

- Token 统计实时性 ≤ 5 分钟

### 10.4 合规要求

- AIGC 内容标识（必做）
- 违禁内容前置审查（必做）
- 用户隐私（手机号等）加密存储、脱敏日志
