## 1. 项目概述与定位

### 1.1 产品定位

智枢AI 是一个 **AI SaaS 多租户超级应用**，为中小企业与个体经营者提供"**内容创作 + 获客 + 招聘 + 裂变**"的一站式 AI 经营工具集。核心价值主张：

- **AI创作工厂**：一句话生成图文 / 图片 / 视频 / 数字人内容，自动沉淀素材库
- **智能获客**：自动采集潜客线索，辅助精准营销
- **智能招聘**：AI 自动猎头，岗位发布 → 简历筛选 → 邀约全流程
- **推荐分享**：分享裂变 + 转介绍返佣，驱动增长
- **AI 助手**：企业策划 / 经营诊断对话式生成，一键导出 Word/Excel/PPT/PDF（桌面版与 APK 端均提供）

### 1.2 目标用户

| 角色 | 说明 | 典型账号 |
|---|---|---|
| **Admin 管理员** | 平台开发者 / 总后台 | 18601655222 |
| **Agent 代理商** | 区域代理，管理名下客户与收益 | 13900000099 |
| **Customer 客户** | 终端付费用户，使用全部业务功能 | 13800000001 |

### 1.3 系统架构（桌面化后）

| 层级 | 技术 | 目录 | 部署 |
|---|---|---|---|
| 桌面客户端（产品主形态） | Tauri 2.x（Rust 主进程 + 系统 WebView2），前端为静态化 SPA（Next.js 14 产物） | `web/`（前端源）+ `desktop/`（Tauri 工程） | Windows 安装包 NSIS/MSI 分发，tauri-plugin-updater 自动更新 |
| 后端 API | Express 4 + TypeScript + Prisma ORM + MySQL | `server/` | 腾讯云 CVM 香港 150.109.60.130 / TDSQL-C MySQL 172.19.0.13:3306 |
| 移动端 APK | Expo SDK 52 + React Native 0.76 | `apk/` | 应用商店 / 侧载 |
| 公共服务网页 | 静态 SPA（分享落地页 / 下载页 / 隐私条款） | `web/out` 对应静态产物 | `baizhiji.net` 静态托管 |
| 共享类型 | TypeScript | `shared/` | — |

**形态边界（用户已确认）**：系统主形态不使用 Web 端——客户 / 代理商 / 管理员日常操作界面（登录、AI创作工厂、智能招聘、智能获客、推荐分享、代理商门户、管理后台）全部为**安装的桌面软件**，浏览器不再作为产品入口。但"只有网页才能实现的功能"全部保留：① **业务网页**——分享码落地页（被分享者扫码后打开网页查看/转发，属推荐分享业务线核心链路）、安装包/APK 下载页、隐私政策/服务条款；② **技术性网页自动化**——Playwright 浏览器自动化（自媒体平台扫码授权登录、内容自动发布、招聘职位采集、智能跟评），它跑在服务端，自动化操作的是**第三方平台网页**（抖音创作者中心、招聘网站等），不属于本系统 Web 端，与桌面化改造完全兼容。

### 1.4 业务模式

SaaS 订阅制 + 代理分销：
- 客户付费开通功能 → 消耗 AI Token
- 代理商发展客户 → 获取佣金（推荐分享 / 转介绍）
- Admin 平台运营 → API 服务商配置下放、品牌定制、公告、数据总览

### 4.1 模块定位

AI 创作工厂是智枢AI 的核心价值入口。用户选择内容类型 → 系统按"多阶段 AI 流水线"自动完成：**爆款分析 → 大纲 → 初稿 → 反AI化 → 配图/视频生成 → 合规审查 → 质量评审 → 定稿**，最终内容自动保存至素材库。

| 图片生成 | 多模型并行出图 → 质量增强 → 择优 | 图片 |
| 电商详情页 | 商品卖点 → 详情页文案 + 配图 | 图文 |

| 企业宣传视频 | 企业介绍视频脚本 + 生成 | 视频 |
| 产品宣传视频 | 产品营销视频 | 视频 |
| 探店视频 | 探店类视频 | 视频 |
| 真人MV视频 | 音乐 + 人像 MV | 视频 |
| 萌宠卡通短视频 | 卡通风格短视频 | 视频 |

### 4.3 智能剪辑创作类目（第 11 类目，桌面版优先）

**定位**：AI 创作工厂第 11 个创作类目，与其它"生成类"类目最大的区别是——**输入是用户上传的多个视频素材，输出是系统自动剪辑合成的一条成片**，即"多素材进 → 一条成片出"，用户无需任何剪辑技能。

**用户操作流程**：桌面端上传多个视频素材（可混入图片/音乐）→ 输入剪辑需求描述（可选，如"把这几段剪成一条 30 秒产品宣传视频"）→ 勾选所需剪辑能力 → AI 自动处理 → 输出成片视频 → 预览 / 下载 / 一键入素材库 / 发布。

**能力清单（8 项）**：

| 能力 | 说明 | 引擎/模型 |
|---|---|---|
| 1. 多素材合成 | 多个视频素材自动挑选、排序、拼接成一条成片 | 本地 FFmpeg + AI 结构编排 |
| 2. 自动剪辑 | AI 智能识别每个素材的精彩片段，去冗余、卡点衔接 | YT-VITA 剪辑点识别 + FFmpeg |
| 3. AI 配音 | 按文案/脚本自动生成配音（TTS），可指定音色/方言，对齐画面节奏 | MiniMax-Speech-2.8-HD / 声音复刻 2.0 |
| 4. 添加字幕 | 按文案生成或语音识别生成字幕 | Kimi K3 / Qwen-Audio-ASR |
| 5. 替换背景音乐 | 替换或添加 BGM，自动匹配节奏 | MiniMax-Music-V2.6 |
| 6. 变速剪辑 | 调整片段播放速度，配合节奏卡点 | FFmpeg（本地） |
| 7. 滤镜调色 | 一键统一多段素材色调，保证成片视觉一致 | FFmpeg 调色渲染（AI 生成调色参数） |
| 8. 片头片尾 | 自动添加品牌化片头片尾 | 模板 + FFmpeg |

**架构承载（桌面版）**：剪辑脚本/剪辑点识别/配音/字幕/BGM/调色参数等 AI 决策走服务端模型路由（详见《AI模型配置最终版》5 智能剪辑专属产线）；视频物理合成（拼接/变速/字幕烧录/混音/调色渲染）由桌面端本地 FFmpeg 引擎执行，不消耗模型视频生成配额、不受网络影响。与 APK 端 `AIEditScreen`（现为单视频 + 自动剪辑/字幕/BGM/变速/滤镜/片头片尾 6 项）的关系：APK 端为移动轻量实现，桌面版为完整版（新增多素材合成、AI 配音、剪辑点智能识别）。

**入口（待开发）**：桌面版 AI 创作工厂新增"智能剪辑"类目——`web/lib/ai/category-config.ts` 新增 `smart-clip` 分类 + 后端剪辑合成 API（`/api/ai/video-edit`）+ 桌面端剪辑工作台页面（多素材上传/能力勾选/进度预览）。

### 4.4 后端承载

## 7. M6 AI 模型配置与管理（《AI模型配置最终版》执行摘要）

> 完整规格见 `docs/AI模型配置最终版.md`（唯一权威配置文档，基于实测后的 `category-config.ts`）。本章为开发需求视角的执行摘要，**新功能开发必须遵守本章的模型路由与横切关卡规范**。

### 7.1 服务商与模型体系（三服务商）

当前桌面版复用的前端配置 `web/lib/ai/category-config.ts` 已注册的模型清单（**配置层已实现**）：

| 服务商 | 能力域 | 已注册模型 |
|---|---|---|
| 腾讯云 TokenHub | 文本 | DeepSeek V4 Pro、混元 Vision 2.0（多模态） |
| 阿里云百炼 | 文本/图像/视频/TTS | Qwen 3.7 Max、Qwen Max、Qwen 3.7 Plus、Qwen 3.8 Max、千问图像 3.0 Pro、千问图像 Max、千问图像编辑、千问 TTS Plus |
| 火山方舟（配置中） | 视频 | 可灵 KLING 3.0、混元视频 1.5、优图视频 2.0、Vidu Q3 Pro/Turbo、HappyHorse 1.1 T2V / 1.0 VideoEdit、数字人（数人） |
| 第三方接入 | 图像/语音 | 混元 Image 3.0/Lite、WAN 2.7 图像 Pro、Z-Image Turbo、Kimi K3、MiniMax Speech 2.8 HD |

### 7.2 五大横切能力（所有产线必经）

1. **违禁内容检测（Content Safety Gate）**：文本/图片生成前后安全审查，拒绝违规输出
2. **去 AI 化检测（Anti-AI Detector）**：反AI化重写，降低机器味（小红书口语化等）
3. **爆款内容创意（Viral Gene Injector）**：生成前爆款意图分析，注入流量基因
4. **质量优先（Quality Gate）**：多模型交叉评审，择优输出
5. **AIGC 标识合规（AIGC Labeling Gate）**：生成内容自动加 AIGC 标识，符合监管要求

### 7.3 模型路由规则（开发必须遵守）

- 每类任务有 **primaryModel + fallbackModel**（主模型失败自动切换备选）
- 关键参数（temperature / top_p / frequency_penalty）在 `category-config.ts` 中按阶段配置（桌面版复用）
- **成本控制**：文本高性价比默认 DeepSeek/Qwen Plus 级，创意发散才用旗舰；图片按 n 张批量生成控制成本
- **API Key 管理**：Admin 在 `/api/admin/api-providers` 配置各服务商密钥，密钥加密存储；桌面版 AI 请求经 **Rust 主进程 AI 代理**转发（密钥存系统凭据管理器，不出主进程、不落前端），客户自带 Key 同样存系统凭据管理器

### 7.4 商用级待完善项

- [ ] 模型健康度监控 / 自动降级告警
- [ ] 按客户等级的模型权限分级（免费版/专业版/企业版用不同档位模型）
- [ ] Token 消耗月度报表（`/api/token-stats` 已具备基础，需可视化）
- [ ] 模型动态路由策略（按负载/价格/质量实时选择）

## 10. 商用级整体要求

### 10.1 功能完整度（验收标准）

- [ ] Customer 端能**独立完成**四大业务线全部核心流程（创作→素材→获客→招聘→分享）
- [ ] Agent 端能管理客户、查看收益、正常结算
- [ ] Admin 端能配置服务商、管理代理、发布公告、监控全平台
- [ ] APK 端 AI 助手八大场景 + 四格式文档导出全链路可用
- [ ] 桌面版干净环境安装 → 首次启动 → 三角色登录 → 核心功能 → 卸载，无残留（M1 出口标准）
- [ ] 三角色登录验证脚本通过（`scripts/verify-login.sh` 返回 HTTP 200）
- [ ] Playwright 网页自动化四链路回归通过（扫码授权 / 内容发布 / 职位采集 / 智能跟评）

### 10.2 安全要求（强制）

- 参数化查询（100% 禁止 SQL 拼接）
- 所有输入 Zod Schema 校验
- 密钥经环境变量 + 服务商配置管理，禁止硬编码；桌面版 AI 密钥存系统凭据管理器，不出 Rust 主进程
- 全局限流 + 敏感端点限流
- CORS 白名单、Helmet 安全头
- 审计日志（敏感操作全记录）

### 10.3 性能要求

- 生成类任务异步化（任务中心模式），避免长请求阻塞
- 图片/视频生成走任务轮询或 WebSocket 通知
- Token 统计实时性 ≤ 5 分钟

### 10.4 合规要求

- AIGC 内容标识（必做）
- 违禁内容前置审查（必做）
- 用户隐私（手机号等）加密存储、脱敏日志
